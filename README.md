# Portfolio Backend

API REST desenvolvida em Node.js + Express + PostgreSQL.

## Setup Local

```bash
npm install
```

Crie arquivo `.env` baseado em `.env.example`.

### Rodar em desenvolvimento

```bash
npm run dev
```

API roda em `http://localhost:3000`
Swagger disponível em `http://localhost:3000/api-docs`

### Build

```bash
npm run build
```

## Variáveis de Ambiente

Veja `.env.example`

## Deploy

Conectar este repo ao Render/Railway automaticamente.
